# 견적서 만들기

이 폴더의 파일:
- `company.md` — 회사 고정 정보(공급자 칸)와 기본 조건 문구. **회사 정보는 여기서만 읽는다.**
- `prices.csv` — 단가표. **단가는 여기서만 가져온다.**
- `assets/quote-template.html` — A4 견적서 양식. `{{토큰}}`만 채운다.
- `scripts/render.py` — 채운 HTML을 PDF로 만든다(크롬·엣지 필요).

## 절대 규칙

1. **단가를 지어내지 않는다.** 모든 단가는 `prices.csv` 에서 가져온다.
   단가표에 없는 품목은 금액을 비우고 `확인 필요`로 표시한다(템플릿 주석의 예시 행). 비슷한 품목 단가로 추정하지 않는다.
2. **요구사항에 없는 품목을 넣지 않는다.** 필요해 보이면 표에 넣지 말고 사용자에게 "○○도 넣을까요?"라고 묻는다.
3. **계산은 칸마다 보이게.** 세부 항목 아래(`.d`)에 `수량 × 단가`를 적는다. 합계는 직접 다시 더해 검산한다.
4. **할인은 단가를 깎지 않는다.** 소계 아래 `할인` 행을 따로 두고, 할인율(약 ○%)과 사유 한 줄(예: "본 건에 한함")을 적는다.
5. **회사 정보는 company.md 값 그대로.** 대화에서 들은 회사 정보로 바꾸지 않는다. 바뀌었다면 company.md 를 먼저 고치자고 말한다.
6. **도장은 기본으로 넣지 않는다.** `{{도장}}` 은 빈 문자열. company.md 에 실제 도장 스캔 이미지 경로가 있을 때만 `<img class="seal" src="파일경로">` 로 넣는다. 도장을 그림으로 그려 만들지 않는다.

## 절차

1. **입력 확인** — 건명, 수신(회사명), 참조(담당자), 날짜, 요구사항. 모르는 값은 묻거나 `(○○ 기입)` 으로 남긴다.
2. **품목표 만들기** — 요구사항을 품목·수량으로 바꾸고, 단가표에서 단가를 찾아 `금액 = 수량 × 단가`.
3. **합계 계산**
   - 공급가액 = 품목 금액 합 − 할인
   - 부가가치세 = 공급가액 × 10% (원 단위 반올림하지 말고 원 미만만 버림)
   - 합계 = 공급가액 + 부가가치세
   - 🔸 고객이 **"부가세 포함 ○○원에 맞춰 달라"** 고 하면: 공급가액 = 총액 ÷ 1.1 (원 미만 버림), 부가세 = 총액 − 공급가액.
     끝수가 지저분해도 그대로 쓴다. 차액은 할인 행으로 흡수한다(단가는 그대로).
4. **양식 채우기** — `assets/quote-template.html` 을 작업 폴더로 복사해 `{{토큰}}` 을 모두 채운다.
   - 회사 칸: `{{회사명}} {{로고}} {{대표자직함}} {{대표자}} {{사업자번호}} {{주소}} {{연락처}} {{도장}}` ← company.md
   - `{{견적금액}}` = `₩6,600,000`, `{{금액단서}}` = `(부가세 포함)`, `{{단위표기}}` = `(단위 : 원)`
   - `{{유효기간}}` = company.md 기본 조건(예: `2026년 10월 30일까지 (30일)`)
   - `{{ITEM_ROWS}}` = 품목 `<tr>` 들(템플릿 주석 예시 참고), `{{기타사항}}` = `<li>` 목록
   - 일정이 필요 없으면 `.sched` 블록을 통째로 지운다. 필요하면 `{{일정_부제}}`, `{{일정_STEPS}}`(`<div class="st"><span class="n">1</span><span class="w">1주</span><span class="t">기획</span></div>`).
5. **PDF 만들기** — `python3 <이 폴더>/scripts/render.py 채운파일.html 견적서.pdf`
   파일명 예: `견적서_<수신처>_<건명>_YYYYMMDD.pdf`
6. **발송 전 확인** (사용자에게도 요약해서 보여준다)
   - `확인 필요` 로 남은 칸이 있는지
   - 합계를 다시 더해 맞는지, 할인율 표기가 맞는지
   - company.md 의 **옛 표기** 목록에 있는 말이 PDF에 남아 있지 않은지(검색)
   - 견적서를 여러 장(총괄 + 항목별) 낼 때는 **모든 장의 숫자가 일치**하는지
   - PDF를 열어 표가 잘리거나 마지막 장에 한두 줄만 넘어가지 않았는지

## 함정

- 금액 칸은 **그 줄의 합계**다. 합계를 낼 때 수량을 한 번 더 곱하지 않는다.
- 단가표에 비슷한 이름이 여러 개면 고르지 말고 사용자에게 어느 것인지 묻는다.
- 큰 할인(20% 이상)은 사유가 없으면 "원래 견적이 부풀려졌다"고 읽힌다. 사유를 꼭 적는다.
- 견적서는 실제로 나가는 문서다. 수신처 회사명·담당자 이름 오타를 마지막에 한 번 더 본다.
